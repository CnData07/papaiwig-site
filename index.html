常见问题

我的数据存在哪里？会不会丢？

数据默认保存在你自己的手机本地。如果你登录了 iCloud 并开启了同步， 还会同时保存在你本人 iCloud 的私有空间里。

我没有服务器、拿不到你的任何数据（详见 隐私政策）。也正因如此，建议你定期做一次导出备份 —— 手机丢了、换机、误操作清空时，备份就是唯一的取回路径。

路径：我的 → 设置 → 导出 / 备份，可以导出 CSV 表格或 JSON 原始数据。

iCloud 同步没生效，设置里显示「仅本机」

按顺序检查这几项：

  • iPhone 上已登录 iCloud（系统设置 → 你的名字）
  • 系统设置 → 你的名字 → iCloud → 云盘（iCloud Drive）已打开
  • 系统设置 → 你的名字 → iCloud → 「毛娘派派」的开关是打开的
  • 网络通畅（同步要联网；飞行模式下只走本机）

都正常的话，等几分钟会自动同步。若仍显示「仅本机」，把 App 从后台划掉重开一次； 还是不行就发邮件给我，附上设置页那张截图的「同步」一栏。

注意：不同设备上的数据要合并，前提是两边都登录了同一个 Apple ID。

买过 Pro，换手机 / 重装之后怎么恢复？

买断是记在你的 Apple ID 上的，不会丢。新设备上用同一个 Apple ID 登录后：

打开 我的 → 升级派派 Pro，点页面下方的 「已经买过了？恢复购买」 即可，不需要再付一次钱。

如果点了没反应，先确认设备已登录 App Store 账号、网络正常，然后重开 App 再试一次。

免费版能建多少单？兑换码怎么用？

免费版同时在做的（进行中）订单最多 30 单。 注意这个上限只统计「进行中」—— 做完归档成「已完成」的单不再占额度， 所以单子越攒越多也不会被锁死。

另外，它只限制「新建」，不会回收你已经有的任何数据： 超出上限时只是拦下新建动作，手上的单照旧，进度、金额、排期都不动。

想要更高的上限，可以进 QQ 粉丝群 953282953 领一枚兑换码， 在 我的 → 设置 → 兑换码 里输入即可。兑换码只提高免费额度上限， 不赠送 Pro 权益；一次性买断 Pro 则完全不设上限。

交期提醒没有响？

交期提醒是本地通知，需要系统授权。检查：

  • 系统设置 → 通知 → 毛娘派派 → 允许通知，且没被设成「静音」
  • 系统设置 → 专注模式 / 勿扰模式是否正在拦截
  • 订单上是否填了交付日期（没填日期就不会有提醒）

提醒默认在交期前几天和交期当天早上 9:00 各来一次。

订单建错了，能删掉吗？

没有「删除」，只有「取消订单」—— 这是有意的： 订单就是你的账，删掉容易对不上。取消后记录仍在，随时能改回任何状态。

  • 在订单列表右滑 → 「取消订单」
  • 或进订单详情 → 右上角 ⋯ → 取消订单
  • 取消后可以在「已取消」筛选里找到它，改回其它状态
怎么把数据彻底清掉？

App 内：我的 → 设置 → 清空数据。清空前 App 会自动在本地留一份 JSON 快照 （可在「导出 / 备份」里取回），清空会同步到 iCloud 上的所有设备。

想连 iCloud 上的副本一起删除：系统设置 → 你的名字 → iCloud → 管理账户存储 → 选中「毛娘派派」→ 删除数据。

卸载 App 只会清掉本机数据，iCloud 上的那份需要按上一段单独删除。

App 需要什么系统版本？
